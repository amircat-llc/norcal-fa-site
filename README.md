# NorCal Food Addicts (norcalfoodaddicts.com)

Static recreation of the FA Bay Area landing page (fa.localgrp.news) using official FA brand colors
from foodaddicts.org (`#698db1` blue, `#ed7037` orange accent, `#221f20` charcoal).

- `index.html` – page content
- `styles.css` – styles
- `meetings.json` – weekly meeting list (edit this to update meetings)
- `app.js` – meeting search/filter, cards/table, and add-to-calendar links

Run locally: `python3 -m http.server 8080` and open http://localhost:8080/.
No build step; deploy the folder as-is to any static host.
